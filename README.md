# 🎙️ 24-H Voice

> تشغيل حسابك تلقائيًا داخل روم صوتي على Discord على مدار 24/7.

---

## ⚙️ طريقة التشغيل

### 01 — إنشاء ملف `.env`

أنشئ ملفًا باسم `.env` داخل مجلد المشروع، ثم أضف البيانات التالية:

```env
TOKEN=ضع_توكن_حسابك
CHANNEL_ID=ضع_ايدي_روم_الفويس
GUILD_ID=ضع_ايدي_السيرفر
```

### 📌 البيانات المطلوبة

| المتغير | الوصف |
|---|---|
| `TOKEN` | توكن الحساب |
| `CHANNEL_ID` | ID الروم الصوتي الذي تريد الدخول إليه |
| `GUILD_ID` | ID السيرفر |

---

### 02 — تثبيت وتشغيل المشروع

بعد إضافة البيانات المطلوبة، افتح **Terminal** داخل مجلد المشروع وقم بتثبيت المتطلبات:

```bash
npm install
```

بعد انتهاء التثبيت، قم بتشغيل المشروع:

```bash
node index.js
```

---

### 03 — التشغيل 24/7 ☁️

للتشغيل بشكل مستمر، قم برفع المشروع على استضافة تدعم تطبيقات **Node.js**، ثم قم بتشغيل المشروع عليها.

بعد التشغيل، سيحاول البرنامج إبقاء الحساب متصلًا بالروم الصوتي المحدد على مدار **24/7**.

---

## ✨ المميزات

## 📋 المتطلبات

- **Node.js 18 أو أحدث**
- استضافة تدعم **Node.js**
- حساب Discord
- `Guild ID`
- `Channel ID`

---

## 🔐 الأمان

> ⚠️ لا تشارك ملف `.env` أو الـ `TOKEN` الخاص بحسابك مع أي شخص.

ويُفضل إضافة `.env` إلى ملف `.gitignore` حتى لا يتم رفعه إلى GitHub:

```gitignore
.env
node_modules/
```

---

## ⚠️ تنبيه

استخدام **User Token** أو تشغيل حساب مستخدم آليًا قد يخالف شروط Discord، وقد يؤدي إلى تقييد أو إيقاف الحساب.

**استخدم المشروع على مسؤوليتك الخاصة.**
